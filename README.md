# 🎬 CineMatch

Sistema de recomendação de filmes com **Python + IA**.

O CineMatch utiliza a **API da Groq (LLaMA 3.1)** para recomendar 3 filmes com base no ator, diretor ou filme favorito do usuário.

## 🛠️ Tecnologias

* Python
* Tkinter
* Groq API
* LLaMA 3.1
* Pandas
* IMDb Datasets

## 🚀 Como executar

Clone o projeto:

```bash
git clone https://github.com/jukawashimo/CineMatch.git
cd CineMatch
```

Instale as dependências:

```bash
pip install pandas groq
```

Configure sua chave da Groq como variável de ambiente:

```bash
GROQ_API_KEY="sua_chave_aqui"
```

Execute:

```bash
python CineMatch.py
```
